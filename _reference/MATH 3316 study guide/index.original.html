Explanatory vs Response Variables

The one question that decides it

Ask: "Which variable could cause or predict the other?"

  • Explanatory variable (x): the one that explains, predicts, or influences. Goes on the x-axis.
  • Response variable (y): the outcome being measured/predicted. Goes on the y-axis.
Memory hook: eXplanatory → x. The thing you'd manipulate or that comes first in time is usually x.

Quick examples

  • Time (x) explains radioactive count (y) — time drives decay.
  • Highway fuel use (x) explains CO₂ emissions (y) — more fuel ⇒ more CO₂.
  • Drinks consumed (x) explains blood alcohol content (y).
  • Day of week (x) explains study time (y).
Watch out: sometimes either direction is defensible (e.g. detergent price vs quality). Pick the causal story that matches the prompt.

Scatterplots: Form, Direction, Strength

Describe every scatterplot with these three words + check for outliers.

Form

Linear (straight band) or curved/nonlinear (e.g. exponential decay bends).

Direction

Positive (rises L→R) or negative (falls L→R).

Strength

Strong (tight band), moderate, or weak (lots of scatter).

Outliers vs influential points: an outlier falls far from the pattern in the y-direction; an influential observation sits at an extreme x and can tip the regression line. (e.g. O'Doul's near-beer: very low alcohol but ~70 cal — an outlier above the line.)
Exam tells: equal x-steps with unequal y-drops ⇒ curved, not linear (radioactive decay). Tight band rising ⇒ strong, positive, linear.
3

Correlation r

r measures the strength and direction of a LINEAR relationship only.

  • Range: −1 ≤ r ≤ 1.
  • r > 0 positive, r < 0 negative, r ≈ 0 no linear relationship.
  • Near ±1 = very strong; |r| ≈ 0.5 = moderate.
  • No units, and switching x and y doesn't change r.
Cautions: r only works for linear form — a perfect curve can still have r far from ±1. r is not resistant (outliers pull it). Strong r ≠ causation.
Reference values: CO₂ vs highway fuel had r = 0.97 → "very strong, positive, linear." Use the z & stats tools below to sanity-check.
4

Least-Squares Regression Line

ŷ = a + bx
  • b = slope = predicted change in y for each +1 unit of x.
  • a = intercept = predicted y when x = 0.
  • Predict: plug an x into the equation. Round only at the end.

Worked: y = 15 + 20x

slope = 20, intercept = 15. At x = 30: y = 15 + 20(30) = 615. At x = 0 ⇒ 15; x = 60 ⇒ 1215. A positive slope ⇒ line rises L→R.

Worked: CO₂ = −10.49 + 29.07·(FuelHwy)

Each +1 L/100km adds ~29.07 g/km CO₂. Predict at x = 8.0: −10.49 + 29.07(8) = 222.07 g/km.

Fit check: the line fits well when the points sit close to it — i.e., the vertical distances (residuals) are small. High |r| ⇒ tight fit.

Formulas if given summary stats: b = r·(sy/sx) and a = ȳ − b·x̄. The line always passes through (x̄, ȳ).

5

Residuals & Cautions

residual = observed y − predicted ŷ
  • Positive residual = point above the line; negative = below.
  • Sum of residuals = 0 (in theory). If they're rounded, the sum is a tiny nonzero value due to rounding — not chance or error.
  • A residual plot with no pattern ⇒ a line is appropriate.

Worked: dominant = 0.886 + 1.373·(nondominant)

nondom = 21.0, dom = 40.3 ⇒ pred = 29.719 ⇒ residual = +10.58. nondom = 31.5, dom = 36.9 ⇒ pred = 44.14 ⇒ residual = −7.24.

Correlation ≠ causation. A lurking variable can drive both. Big hospitals correlate with longer stays because they treat sicker patients (severity is the lurker). Tea + nursing-home cheer? The lurker is the students' social visits.

Two-Way Tables: Marginal & Conditional

Marginal distribution

One variable's totals ÷ grand total × 100. Lives in the table's margins (row or column totals).

Conditional distribution

Within one row or column: cell ÷ that row/column total × 100. "Given X, what % are Y?"

Worked: marginal distribution of country (grand total = 4576)

CountryTotalPercent
Canada1763.85%

U.K.47510.38%
U.S.206945.21%

Each % = country total ÷ 4576 × 100. They sum to 100%.

Tip: marginal uses the grand total; conditional uses a single row/column total. Rounded percents should land at 100% (±0.01 from rounding).
7

Normal Distributions & z-scores

A Normal model is the bell curve, written X ~ N(μ, σ) — mean μ, standard deviation σ.

The standard normal is the special case Z ~ N(0, 1). We convert any value to a z-score so we can use one table.

Standardize

z = (x − μ) / σ

How many SDs x is from the mean.

Work backward

x = μ + zσ

Given a z / percentile, get the value.

Worked: X ~ N(12, 0.015)

  • x = 11.97 ⇒ z = (11.97 − 12)/0.015 = −2
  • P(X < 11.97) = P(Z < −2) ≈ 0.0228 (2.28%)
  • P(X > 11.97) = 1 − 0.0228 = 0.9772
Probability process: (1) write μ, σ; (2) find z; (3) z-table gives area to the LEFT; (4) "greater than" ⇒ 1 − left; (5) "between" ⇒ bigger left − smaller left.

Percentiles (work backward)

25th percentile means area-left = 0.25 ⇒ z ≈ −0.67 ⇒ x = 12 + (−0.67)(0.015) ≈ 11.99.

8

Empirical Rule & Normal Plots

68%

within 1 SD: μ ± σ

95%

within 2 SD: μ ± 2σ

99.7%

within 3 SD: μ ± 3σ

Worked: μ = 100, σ = 15 (IQ)

1 SD: 85–115 (≈68%) · 2 SD: 70–130 (≈95%) · 3 SD: 55–145 (≈99.7%).

Tail tricks: below μ−2σ ≈ 2.5%; above μ+σ ≈ 16% (since the middle 68% leaves 32% split between two tails).

Normal probability plot: if the points fall on a roughly straight line, the data is approximately Normal. Strong bends or obvious outliers ⇒ not Normal.

Say on the exam: "The data appears approximately Normal because the points in the normal probability plot follow a roughly straight-line pattern."

One-Page Cheat Sheet

Formulas

z = (x − μ)/σ

x = μ + zσ

ŷ = a + bx

b = r·sy/sx · a = ȳ − b·x̄

residual = y − ŷ

Empirical Rule

±1σ → 68% · ±2σ → 95% · ±3σ → 99.7%

below μ−2σ ≈ 2.5% · above μ+σ ≈ 16%

z-table moves

table = area to LEFT

"greater than" → 1 − left

"between" → bigger − smaller left

Words to use

scatterplot: form · direction · strength + outliers

r: linear only, no units, not resistant

marginal = ÷ grand total; conditional = ÷ one row/col

Last-Minute Tips

If you only get one pass before the exam:

  • Memorize z = (x − μ)/σ and x = μ + zσ — half the exam is these two.
  • 68–95–99.7 cold, plus the tail shortcuts (2.5%, 16%).
  • Read the question's direction: "less than" = table value; "greater than" = 1 − table; "between" = subtract.
  • Normal plot = straight line ⇒ normal. Say it in one sentence.
  • Don't round mid-problem. Carry full precision, round the final answer to the requested places.
  • Correlation ≠ causation — name the lurking variable when asked.
