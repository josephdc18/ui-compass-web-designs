# SEO Audit Guide

## Key themes (paraphrased)
- Three-phase audit calendar: technical (days 1-7), on-page (days 8-14), off-page (days 15-21).
- Technical: URL structure, internal linking, sitemap freshness, mobile responsiveness, Core Web Vitals (LCP <2.5s, FID <100ms, CLS <0.1), robots.txt, canonical tags, 404 sweep.
- On-page: title <60 chars, meta <160 chars, H1/H2/H3 hierarchy, alt text, content depth.
- Off-page: backlink quality, link diversity, toxic-link disavowal, NAP consistency.
- Free tools: Google Search Console, PSI, Screaming Frog (free), GTmetrix, WAVE.
- Paid tools: Ahrefs, SEMrush, Screaming Frog Pro, DeepCrawl, Botify.
- Audit cadence: every 6-12 months. Effort: 8-16 hours per audit.

## Quotable claims / stats (verify before reuse)
- 20-50% organic traffic lift within 3-6 months after fixing audit issues (no source given, weak).
- 8-16 hours per comprehensive audit.
