# Essential Features for a Small Business Website

## Key themes (paraphrased)
- Mobile-first design. 60%+ of traffic is mobile. Already covered.
- Local SEO + Google Map integration. GBP as second homepage. Already covered.
- Sub-second load. 1s delay = 7% conversion drop. Already covered.
- SEO structure: semantic HTML, meta, OG, schema, clean URLs. Already covered.
- Lightweight AI personalization: location-based CTAs, time-of-day messaging, behavior-based content highlighting.
- Trust + security: SSL, PCI compliance, Stripe/PayPal, security badges, visible contact info, current legal pages.

## Quotable claims / stats (verify before reuse)
- 60%+ of global traffic is mobile.
- 1-second delay = up to 7% conversion drop.
