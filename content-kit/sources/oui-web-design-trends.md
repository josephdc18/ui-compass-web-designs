# Web Design Trends

## Key themes (paraphrased)
- Sub-3-second load is now the floor, not the ceiling.
- AI implementation should be invisible: backend personalization, automated alt text and meta descriptions, intelligent lead routing. NOT a chatbot bubble.
- Two parallel visual trends: bold/expressive (color, organic shapes) vs calm/minimalist (whitespace, structured).
- Heavy animations actively penalize speed and conversion. The trend is away from auto-play motion.
- Local SEO emphasis growing in mid-tier markets.
