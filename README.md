## Handing this project to an LLM

Point your LLM at **`LLM/CLAUDE.md`** first. That file is tailored to this export — it enumerates the feature packs, page list, placed sections, and pack-specific CSS namespaces. The companion `LLM/EXECUTION-RULES.md` covers discipline rules (no invented selectors, read before writing, preserve `[data-pb-section]` scoping, etc.).

The `_reference/` folder exists for LLM context only:
- `_reference/original-template/` — the starting template scrape, verbatim.
- `_reference/section-sources/<category>/<file>.html` — the raw CodeStitch HTML for every placed section, **pre-customization**.

## D1 Database Setup (for contact form)

The contact form saves submissions to a Cloudflare D1 database.

```bash
# 1. Create the database
wrangler d1 create ui-compass-web-designs-db

# 2. Copy the database_id from the output and paste it into wrangler.toml

# 3. Run the schema migration
#    Local:
wrangler d1 execute ui-compass-web-designs-db --local --file=./database/schema.sql
#    Production:
wrangler d1 execute ui-compass-web-designs-db --file=./database/schema.sql
```

**D1 binding name:** `DB` (used by `functions/api/form.js` as `env.DB`)
**Table:** `form_submissions` (defined in `database/schema.sql`)

## Decap CMS Setup (content editing at /admin/)

1. Create a GitHub OAuth App at https://github.com/settings/developers
   - Homepage URL: `https://yourdomain.com`
   - Authorization callback URL: `https://yourdomain.com/api/auth`
2. In Cloudflare Pages settings, add environment variables:
   - `GITHUB_CLIENT_ID` — your OAuth App Client ID
   - `GITHUB_CLIENT_SECRET` — your OAuth App Client Secret
   - `CMS_ALLOWED_USERS` — (optional) comma-separated GitHub usernames
3. Update `src/admin/config.yml`:
   - Set `repo` to your GitHub username/repo
   - Set `base_url` to your domain

## Deploy to Cloudflare Pages

1. Push this repo to GitHub.
2. In the Cloudflare Pages dashboard, create a new project and connect your repo.
3. Set build command: `npm run build`
4. Set output directory: `public`
5. Run `npm run init` locally to automate D1 creation, secret setup, and first deploy.
