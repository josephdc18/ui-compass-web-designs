# What is a Subdomain and Why You Might Need One

## Key themes (paraphrased)
- A subdomain is a separately addressable section under your main domain (shop.example.com).
- The main reason to use one is performance isolation: keep heavy login portals off the marketing site.
- Most small businesses do not need one.
- Search engines treat subdomains as separate sites. SEO does not transfer cleanly.
- Trade-off: more SSL certificates, more analytics setup, more places things can break.

## Quotable claims / stats (verify before reuse)
- Subdomain format: subdomain.mainsite.com.
- Common cases: client portals, admin dashboards, secondary shops, financial customer zones.
