# Website Hosting vs Maintenance

## Key themes (paraphrased)
- Hosting = the server space, bandwidth, SSL, uptime guarantee. It is real estate.
- Maintenance = security patches, backups, content updates, performance tuning, bug fixes. It is upkeep.
- Hosting alone gets you a site that gradually rots. Maintenance alone cannot overcome bad hosting.
- Cost stack: shared hosting $3-10/mo, managed $25-100/mo, static $0-20/mo. Maintenance: freelancer $50-150/mo, agency $100-500/mo.
- Common confusion: a $5/mo shared host and a "we keep an eye on it" promise are not the same thing as a maintenance plan. The owner discovers this 18 months in.
- Bundled offering example: $150/mo all-in for hosting + maintenance + SSL.
