Local Setup
Get the project running on your machine
Install Dependencies Required
Install npm packages
Run in Terminal
bash
cd ui-compass-web-designs npm install
What This Does

Installs all packages listed in package.json

Configure Local Secrets Optional
Fill in .dev.vars for local development
Edit File

Open .dev.vars and fill in any required values. This file is auto-generated and already in .gitignore.

bash
cat .dev.vars
What This Is

Cloudflare Pages uses .dev.vars for local environment variables (equivalent to .env). Your deployed secrets are set separately via npx wrangler pages secret put.

Start Dev Server Required
Make sure everything works locally
Run in Terminal
bash
npm start
Expected Result

Browser opens automatically to http://localhost:8080 with your site

4
Database Setup
Create and configure your D1 database
Create D1 Database Required
Create a Cloudflare D1 database
Run in Terminal
bash
npx wrangler d1 create ui-compass-web-designs-db
Important

Copy the database_id from the output — you need it in the next step

Update wrangler.toml Required
Paste your database ID into the config
Edit File

Open wrangler.toml and replace the placeholder database_id:

toml
[[d1_databases]] binding = "DB" database_name = "ui-compass-web-designs-db" database_id = "paste-your-database-id-here"
Run Local Migrations Required
Set up database tables locally
Run in Terminal
bash
npx wrangler d1 execute ui-compass-web-designs-db --local --file=database/schema.sql
Run Remote Migrations Required
Set up database tables on production
Run in Terminal
bash
npx wrangler d1 execute ui-compass-web-designs-db --remote --file=database/schema.sql
Production

This runs against your live database. Make sure you've tested locally first.

6
CMS Setup
Configure Decap CMS with GitHub authentication
Create GitHub OAuth App Required
Required for CMS login
Steps
  1. Go to GitHub Developer Settings
  2. Click New OAuth App
  3. Set Homepage URL to your site URL
  4. Set Callback URL to https://ui-compass-web-designs.pages.dev/api/auth
  5. Copy the Client ID and generate a Client Secret
Set CMS Secrets Required
Add OAuth credentials to Cloudflare
Run in Terminal
bash
npx wrangler pages secret put GITHUB_CLIENT_ID npx wrangler pages secret put GITHUB_CLIENT_SECRET
Optional

Restrict CMS access: npx wrangler pages secret put CMS_ALLOWED_USERS (comma-separated GitHub usernames)

8
Cron Scheduler
Configure scheduled jobs
Verify Cron Trigger Required
Ensure the cron trigger is in your wrangler.toml
Check wrangler.toml

Your wrangler.toml should contain this trigger block. If not, add it:

toml
[triggers] crons = ["*/5 * * * *"]
How It Works

Cloudflare invokes functions/scheduler/index.js every 5 minutes. Job schedules are configured in the database, not in wrangler.toml.

Set Email Secrets Optional
For email notifications from scheduled jobs
Run in Terminal
bash
npx wrangler pages secret put EMAIL_PROVIDER npx wrangler pages secret put EMAIL_API_KEY npx wrangler pages secret put EMAIL_FROM npx wrangler pages secret put NOTIFICATION_EMAIL
Providers

EMAIL_PROVIDER can be resend, mailgun, or webhook

Set Cache Purge Secrets Optional
For the cache-purge scheduled job
Run in Terminal
bash
npx wrangler pages secret put CF_ZONE_ID npx wrangler pages secret put CF_API_TOKEN
Where to Find

CF_ZONE_ID is on your Cloudflare domain overview page. Create an API token at dash.cloudflare.com/profile/api-tokens
