# Overlooked Web Design Rules

## Key themes (paraphrased)
- Mobile-first non-negotiable. 62% mobile traffic, 53% mobile abandonment over 3s. Already covered.
- Sub-3s load. 1s delay = 7% conversion drop, 3s delay = 32% bounce lift. Already covered.
- Clear value proposition above the fold within 3s. Weak headlines drop engagement 73%. Already partially covered.
- Navigation: 5-7 items max. Confusing nav lifts bounce 25%, hidden pages drop conversion 15%.
- CTA contrast and clarity. Generic CTAs lose 30% of clicks. Wrong placement loses 50%.
- Text density: long paragraphs cut readability 40%. Dense content lifts bounce 30%. 2-3 sentence paragraphs max.
- Trust signals (SSL, testimonials, badges, contact). Missing trust drops conversion 15%, missing security badges lift cart abandonment 20%.

## Quotable claims / stats (verify before reuse)
- 5-7 navigation items max. Confusing nav: 25% bounce lift.
- Long paragraphs: 40% readability drop, 30% bounce lift.
- Wrong CTA placement: 50% conversion drop.
