# Website Security for Small Business

## Key themes (paraphrased)
- 43% of cyberattacks target small businesses. The "we are too small to be a target" assumption is wrong.
- 29% of WordPress hacks specifically trace to vulnerable or out-of-date plugins. The average WordPress site runs 20-30 plugins, each is a separate door.
- 80%+ of breaches involve compromised credentials per Verizon's DBIR. Password hygiene is the single highest-leverage defense.
- The "16+ character password" rule. Length beats complexity for brute-force resistance.
- Free SSL via Let's Encrypt covers the encryption side. Paid security plugins ($5-20/mo) cover the WordPress-specific surface area.
- Update cadence: weekly minimum for CMS sites, immediately for security patches. Static sites can stretch the cadence safely.
- Monitoring tooling baseline: UptimeRobot free tier covers up to 50 sites.
