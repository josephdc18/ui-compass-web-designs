What our website health check covers

Technical checks we run

  • Indexability - Noindex tags, HTTP errors, redirects, HTTPS
  • Meta tags - Title, meta description, viewport, Open Graph
  • Content structure - H1 usage, heading order, empty headings
  • Images - Alt text, missing dimensions, lazy loading hints
  • Security basics - HSTS, nosniff, unsafe external links

What you get

  • A–F grade - Based on high-impact issues
  • Summary - Top priorities across the pages analyzed
  • Action checklist - Evidence and suggested fixes for each issue
  • Full site option - Up to 10 pages via sitemap discovery
  • Export - PDF download and a shareable email checklist

Accessibility checks

  • Landmarks - Presence of <main> and <nav>
  • Link labels - Links without visible text or aria-label
  • Language - Missing lang attribute on <html>
  • Share previews - Missing Open Graph tags

How to use your health check results

1. Start with critical issues (Grade F)

Focus on issues that can block indexing or significantly reduce visibility:

  • Remove noindex directives and fix HTTP errors
  • Enforce HTTPS and reduce redirect chains
  • Add missing title and viewport tags

2. Address quick wins (Grade D-C)

Optimize elements that can improve rankings quickly:

  • Add missing alt text to images
  • Improve titles and meta descriptions
  • Fix heading structure and internal links

3. Enhance content quality (Grade B-A)

Fine-tune your content for better user engagement:

  • Polish headings and on-page clarity
  • Improve accessibility landmarks and link labels
  • Keep iterating and re-audit after updates
