USAGE GUIDE
-----------

LOGO FILES
- Use SVG for web and print when scalability is needed
- Use PNG for digital applications requiring fixed sizes
- All PNG logos are 1024x1024 with 10% padding for consistent appearance
- Choose the appropriate background version based on your use case

FAVICONS
- Upload the entire favicons/ folder to your web root
- Upload pwa-splash.js to your web root
- Add the HTML snippet from favicon-snippet.html to your <head>
- The site.webmanifest enables PWA features

SOCIAL MEDIA
- Use og-facebook.png for Facebook and general Open Graph
- Use og-twitter.png for Twitter cards
- Use og-linkedin.png for LinkedIn posts
- Use og-square.png for Instagram and square formats

BRAND GUIDELINES
- Always maintain clear space around the logo
- Don't stretch, rotate, or alter the logo
- Use provided colors for brand consistency
- See brand-guidelines.html for complete usage rules
