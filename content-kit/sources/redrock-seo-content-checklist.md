# Optimizing Content for SEO

## Key themes (paraphrased)
- Title tag 50-60 chars, H1 with primary keyword, meta description 150-160 chars, keyword in first 100 words. Standard on-page checklist.
- Search intent matching: before writing, read the current top 3 results for the query. Match their format (transactional vs educational), then identify what they missed and fill that gap.
- Word count guideline: 800-1,200 words unless the topic genuinely needs more.
- Treat content as a living document. Update stats, refresh examples, add sections. Publish-and-forget loses to publish-and-improve.
- Plain language writing improves dwell time, which Google reads as a quality signal.
- Keyword cannibalization: each page targets a distinct query with distinct content. (Already pulled in the how-many-pages source.)

## Quotable claims / stats (verify before reuse)
- Title: 50-60 chars. Meta description: 150-160 chars.
- Word count: 800-1,200 typical.
- Keyword placement: title, H1, first 100 words, one subheading, one image alt, URL slug.
