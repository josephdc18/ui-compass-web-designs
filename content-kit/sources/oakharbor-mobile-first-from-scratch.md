# How to Build a Responsive, Mobile-First Website From Scratch

## Key themes (paraphrased)
- Mobile-first means writing the 320px layout first, then progressively enhancing up.
- Mobile styles live at the top of the stylesheet, media queries layer on top with min-width.
- Breakpoint set used: 400, 568, 768, 1024, 1300px.
- Containers usually want width 100%, a max-width cap, and margin auto for centering.
- Plan the HTML by section first. Minimize divs. Use semantic tags.
- Mobile-first is actually easier than desktop-first because content grows into space instead of being squeezed down.

## Quotable claims / stats (verify before reuse)
- Roughly 60% of internet traffic is on mobile devices.
- Designing at 320px covers the smallest realistic phone (iPhone 5SE).
